# Methodology

## Workflow

1. Audit restricted records and apply study-defined eligibility filters.
2. Harmonize screening, examination, demographic, coverage, and area-context variables.
3. Construct generic screening and reported-history indicators.
4. Define a previously unreported outcome when an examination indicator is positive and no corresponding history is reported.
5. Produce descriptive summaries with exact binomial confidence intervals.
6. Fit and diagnose an adjusted logistic-regression model among eligible complete cases.

## Interpretation boundary

The public code documents an analytical pattern, not the results of a named study. Screening and reported-history discordance is a constructed workflow outcome; it is not a clinical diagnosis of error. The observational workflow does not establish causal effects.
