# Data privacy

This portfolio deliberately removes all project-identifying information. It does not disclose an organization, study name, location, sample size, dates, health-condition findings, source variables, results, or internal materials.

The public repository excludes:

- all participant-level inputs and identifiers;
- source-system fields, locations, dates, linkage files, and data dictionaries;
- tables, figures, model estimates, and outputs derived from restricted data;
- project drafts, communications, and other internal materials.

The code uses generic variables to demonstrate a transferable analytical workflow. Authorized inputs belong in `data/private/`, and generated outputs belong in `results/private/`; both paths are ignored by Git.
